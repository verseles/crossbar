# ai-docs

External API documentation stored locally for reference during development.

Place documentation files here for libraries, APIs, and services that plugins
or the core system interact with. This ensures agents and developers have
up-to-date reference material without relying on web searches.

## Structure

- `lua_dardo/` - Lua interpreter API reference
- `github-api/` - GitHub API docs for marketplace
- `bitbar-format/` - BitBar output format specification
