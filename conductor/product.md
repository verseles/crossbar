# Product Guide - Crossbar

## Vision
Crossbar is a revolutionary, cross-platform plugin system that allows users to "Write Once, Run Everywhere." It brings the simplicity of scriptable status bar widgets (like BitBar or Argos) to all major platforms, including desktop (Linux, Windows, macOS) and mobile (Android, iOS).

## Target Users
*   **Developers:** Who want to create system monitoring or productivity tools quickly using their favorite languages (Python, Bash, JS, Lua, Dart, Rust, Go).
*   **Power Users:** Who want a unified, customizable dashboard for system stats, network info, media controls, and automation across all their devices.
*   **System Administrators:** Who need to monitor servers or local services directly from their menu bar or mobile home screen.

## Core Features
*   **Multi-Language Plugins:** Native support for Bash, Python, Node.js, Lua, Dart, Go, Rust, and declarative YAML.
*   **Cross-Platform UI:** Renders as a system tray icon (Desktop), home screen widget (Android/iOS), or persistent notification.
*   **Unified CLI API:** Over 75 built-in commands (`crossbar cpu`, `crossbar battery`, etc.) that abstract platform-specific details.
*   **Secure Configuration:** Auto-generated UI for plugin settings with secure storage for secrets (Keychain/KeyStore).
*   **Adaptive Rendering:** One script output automatically adapts to the target platform's UI conventions.

## Value Proposition
Unlike existing tools that are limited to a single desktop OS, Crossbar provides a consistent, secure, and highly extensible environment that bridges the gap between desktop automation and mobile accessibility.
